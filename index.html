How It Works

Closed-form syscall analysis

Zero black boxes. 100% deterministic. Training computes a mathematical decision surface; inference is a quantized dot product. Every classification produces a JSON proof file — a complete audit trail.

Math, not magic

Most ML in security is a black box. You feed it data, it gives you a probability, and you hope it is right. Planck-99 is different.

We model syscall sequences as 32-dimensional normalized frequency fingerprints. Training computes a closed-form decision surface. At runtime, inference is a deterministic int8 dot product — identical input always yields identical output.

The model generalizes 51× beyond its training ceiling (tested to 117,088 syscalls) because normalized frequency ratios are length-invariant by construction. No neural networks. No stochastic behavior. No runtime training.

Where Planck-99 fundamentally surpasses Exein

Air-Gapped by Design
Exein's eBPF pipeline requires kernel loading tools, exports logs off-device via perf ring buffer, and may need AI model updates — all of which create operational air-gap problems. Planck-99 needs zero network of any kind, ever.
37 KB vs Linux-only
Exein requires a Linux kernel with eBPF support (CONFIG_BPF, CONFIG_BPF_SYSCALL). Planck-99 is 37 KB of pure C — runs on anything with a CPU, from Cortex-M to x64. Opens the entire 21B-device MCU market Exein cannot address.
Compliance Engine
Exein produces observability logs that require external processing. Planck-99 produces a self-contained JSON proof per classification that directly satisfies CRA Article 13 traceability mandates — verifiable with zero proprietary tooling by any insurer, auditor, or regulator.
34 ns Latency
Exein's eBPF pipeline carries overhead from BPF verifier JIT, map lookups, and userspace perf ring buffer communication. Planck-99's closed-form int8 dot product completes in 34 ns median (σ ≤ 14 ns).
Zero Dependencies
Exein requires kernel 4.14+, BPF verifier, GNU/Linux userspace. Planck-99 has zero runtime dependencies — no kernel modules, no BPF, no FPU, no GPU, no AI accelerator, no network. One 37 KB binary.
